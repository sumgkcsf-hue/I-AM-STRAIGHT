# Privacy Policy: shorts-autoreply

shorts-autoreply is a small personal tool. It runs on its owner's own PC and replies to comments on the owner's own YouTube channel (MaskTradeciety).

**What it does**
- It signs in with the channel owner's own Google account, once.
- It reads comments on the owner's own videos.
- It posts a reply to a comment when the comment asks for a link.

**What it stores**
- On the owner's PC only: a sign-in token and a list of comment IDs it already replied to.
- It does not collect, store, sell or share any data about other people.
- It sends no data to any server other than Google's YouTube API.

**Google API data**
The tool's use of information from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
