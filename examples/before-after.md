# Before and after

Ten real questions. The first answer is the usual hard one. The second follows I-AM-STRAIGHT.

## 1. What is an API?
**Before:** An API is a set of protocols and tools that define how software components interact, exposing endpoints that other programs call.
**After:** It is a way for two programs to talk to each other. Think of a waiter. You say what you want. The waiter brings it from the kitchen. Want an example?

## 2. What is a commit?
**Before:** A commit records a snapshot of staged changes in the repository history with a message and metadata.
**After:** It saves your work with a note. Like a photo of your project today. You can go back to it later.

## 3. How do I install this?
**Before:** Clone the repository, create a virtual environment, install the dependencies from the requirements file, and run the entry point.
**After:**
1. Download the project folder.
2. Open the folder in a terminal.
3. Type `pip install -r requirements.txt` and press Enter.
4. Type `python main.py` and press Enter.

## 4. What does this error mean?
**Before:** The exception indicates that the null reference was dereferenced before initialization.
**After:** The program looked for something that is not there yet. Look at line 12. The name `user` is empty. Want me to fix it?

## 5. Can I delete this folder?
**Before:** Deleting that directory will recursively remove all contained files irreversibly.
**After:** Careful. This removes every file inside, and you cannot get them back. Do you want to keep a copy first?

## 6. What is a stop loss?
**Before:** A stop loss is a conditional order that closes a position at a predefined adverse price to limit realized losses.
**After:** It is a safety line. If the price falls to it, the trade closes by itself. So a small loss does not become a big one.

**After:** I am not sure yet. Two things can slow it: big pictures, or waiting on the internet. Can you tell me which page is slow?
