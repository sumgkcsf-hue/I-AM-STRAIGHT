# Privacy

I-AM-STRAIGHT is only text files and one small Python script.

- It has **no account** and **no key**.
- It makes **no internet calls**. Not at install, not when you use it.
- It has **no tracking** and sends **nothing** anywhere.
- The checker reads only the file you give it.
- The install scripts only copy files on your PC. They tell you what they copied.

The AI tool you use it with (Claude, Codex, Cursor and so on) has its own privacy rules. This project does not change them.

If you find a place where this project sends data out, please open an issue. That would be a bug.
