# I-AM-STRAIGHT

**Straight talk. Short answers. Kind words.**

AI helpers often answer with long, hard words. This project makes them talk in easy words, like a kind friend. It is for anyone who knows basic English and wants to understand.

> "Straight" here means **direct and clear**. Nothing more.

## Install (about 1 minute)

You need nothing from the internet. It only copies small text files on your own PC.

**Claude Code, Windows:** open PowerShell in this folder and type:
```
./install.ps1
```
**Claude Code, Mac or Linux:**
```
sh install.sh
```
Then, in Claude Code, type `/i-am-straight`. To stop, say `stop straight`.

**Other tools** (Codex, opencode, Cursor, Gemini, Copilot, Cline, Windsurf) and **local models** (Ollama, LM Studio): see [INSTALL.md](INSTALL.md).
**Any chat AI:** open `PASTE-ME.txt`, copy everything, paste it as your first message.

## What it does

1. Answer first.
2. Short sentences. Easy words.
3. One idea at a time.
4. Numbered steps.
5. Gentle. Never makes you feel small.
6. Says "I am not sure" instead of guessing.
7. Asks before anything risky.

The full rules are in [RULES.md](RULES.md). They are one page.

## Check any answer

```
python checker/straight_check.py answer.txt
```
It tells you, kindly, if an answer is too hard to read. It works offline.
